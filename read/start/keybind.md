## 搭配「Shell」的「按鍵綁定」

| Shell 按鍵綁定  | 功能簡述                   |
| -------------- | ------------------------- |
| `Ctrl + r`     | 過往指令的fzf查詢界面       |
| `Ctrl + t`     | 目前資料夾檔案的fzf查詢界面  |
| `Alt + c`      | `cd`指令的fzf輔助界面      |

> 詳細說明，可以參考冊「fzf 官方的文件 / [Key bindings for command-line](https://github.com/junegunn/fzf?tab=readme-ov-file#key-bindings-for-command-line)」。




## 進到fzf查詢界面的按鍵綁定

| 進到fzf查詢界面的按鍵綁定 | 功能簡述                   |
| ---------------------- | ------------------------- |
| `Enter`                | 確定選取該列                 |
| `Up`                   | 游標向上一列移動             |
| `Down`                 | 游標向下一列移動             |
| `Ctrl + p`             | 游標向上一列移動             |
| `Ctrl + n`             | 游標向下一列移動             |
| `Ctrl + k`             | 游標向上一列移動             |
| `Ctrl + j`             | 游標向下一列移動             |
| `滑鼠滾輪向上`           | 游標向上一列移動             |
| `滑鼠滾輪向下`           | 游標向下一列移動             |
